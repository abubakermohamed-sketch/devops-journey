# DevOps / Cloud Learning Journey

Daily hands-on practice building toward a career in Cloud/DevOps/SRE.
Documenting real progress — including real bugs and how I debugged them.

## Structure
Each folder is one day's work, building on the previous days.

- `day01-wsl-linux-basics/` — Linux fundamentals in WSL2
- `day02` — (Git was folded into Day 1's repo setup)
- `day03-python-basics/` — Python variables, loops, conditionals
- `day04-functions-files/` — Functions, file I/O
- `day05-mini-project/` — Server inventory classifier (Python, functions, dicts, file I/O)
- `day06` — AWS account + IAM setup (console-based, no code)
- `day07` — AWS CLI setup and configuration (console/CLI-based)
- `day08` — First EC2 instance, SSH access, security groups
- `day09-boto3-ec2/` — Python + boto3: programmatic EC2 start/stop/status
- `day10-ec2-cli-tool/` — Full CLI tool for EC2 management (list/start/stop/report)

## Tools & concepts covered so far
Linux/WSL2, Git/GitHub, Python (functions, file I/O, dicts, argparse),
AWS (IAM, EC2, CLI, boto3), security best practices (least privilege, MFA, no hardcoded credentials)
